Clean Architecture Skill
When to Use This Skill
Codebase structure is being designed or modified
Business logic must be separated from frameworks
Procedure
Identify domain, application, and interface layers
Use context7 to confirm clean architecture patterns
Define boundaries and interfaces
Enforce dependency direction
Validate separation of concerns
Output Format
Folder structure
Interface definitions
Layered module organization
Quality Criteria
Framework-independent core
Clear boundaries
Testable business logic
No circular dependencies
